# Pizza Ordering App

This is a simple command-line program written in Dart that simulates a quick pizza ordering workflow. 
I built this application to practice core Dart programming concepts such as handling user input, 
managing conditional logic, and implementing dynamic control loops.

The program runs directly in your terminal and guides you step-by-step through the ordering process. 
It starts by displaying the available menu, where small pizzas cost $5, medium pizzas cost $7, and large pizzas cost $10. 
Once the menu is displayed, it prompts you to select a size and enter the desired quantity. 
The system validates your entries to ensure valid choices and non-negative numbers are given, preventing unexpected crashes. 
After calculating your total payment, it gives you the option to place another order or exit the program smoothly.

### How to Run

* **Check Dart Installation:** Make sure you have the Dart SDK installed. You can verify this by running `dart --version` in your terminal.
* **Open Terminal:** Open your terminal or command prompt window.
* **Navigate to Project:** Move into your project folder using the command `cd path/to/your/project`.
* **Execute Code:** Run the program by typing `dart run main.dart` (replace `main.dart` with your file name if it's different).
* **Follow Prompts:** Enter your pizza size, quantity, and choose whether to place another order when prompted.

This project served as a great hands-on exercise for applying standard input/output operations using `dart:io`, 
handling string normalization and numeric parsing with `int.tryParse()`, and structuring continuous program flows using `while` loops and `switch` statements.
